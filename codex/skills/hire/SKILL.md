Start the HR department. Hire new team members for the agent company. Running the recruiting pipeline from start to finish: interview the user about the goal if the brief is thin, survey the current project and the existing agents, propose a shortlist of new agents (name, role, model, permissions, location), get the user's one-click approval, then have the recruiter spawn and write the hire files.

Follow the org-chart skill — it is the source of truth for the hire format, valid fields, file locations, and the full pipeline. Use it as the checklist for every hire.
